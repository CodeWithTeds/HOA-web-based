DESIGN GUIDELINES (APPLE / MACBOOK INSPIRED UI)

Design Style:

* Follow a clean, minimal, and premium Apple (MacBook-inspired) design.
* Focus on simplicity, whitespace, and smooth visual hierarchy.
* Avoid clutter — every element should have purpose.

Typography:

* Use a font similar to Apple’s San Francisco (SF Pro).
* Recommended fallback fonts:

  * "SF Pro Display"
  * "SF Pro Text"
  * -apple-system
  * BlinkMacSystemFont
  * "Segoe UI"
  * Roboto
  * sans-serif
* Use medium to bold weights for headings and regular for body text.
* Maintain clear font scaling (large hero text, smaller supporting text).

Color Palette (STRICT: 1–3 colors only):

* Primary: Neutral (White / Off-white)
* Secondary: Dark (Black / Dark Gray)
* Accent: Subtle Blue or Gray (Apple-like tone)
* Avoid overly saturated or bright colors.
* Keep everything soft, clean, and professional.

UI Elements:

* Use rounded corners (rounded-xl to rounded-2xl)
* Soft shadows (shadow-md or shadow-lg, not harsh)
* Subtle borders (border-gray-200)
* Smooth hover transitions (transition, duration-300, ease-in-out)

Layout:

* Centered content with max-width (e.g., max-w-6xl or max-w-7xl)
* Generous padding and spacing (py-16, px-6, gap-8)
* Grid-based layout for sections
* Consistent alignment across all components

Buttons:

* Rounded full buttons (rounded-full)
* Minimal style:

  * Primary: dark background with white text
  * Secondary: light background with dark text
* Add subtle hover effects (opacity or slight scale)

Effects:

* Smooth scrolling
* Fade-in animations (optional, subtle only)
* Avoid excessive animations — keep it elegant

Overall Goal:
Create a premium, modern, and clean interface that feels like a MacBook/Apple website — simple, elegant, and highly usable.
